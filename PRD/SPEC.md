# 理賠安心助手 — PRD v3.0.2 等級規格書

> 建立日期:2026-09-19 · 對齊 SPEC v3.0 契約

## §1 產品概述

### 1.1 問題陳述
保戶出險後理賠流程：(1) 要跑醫院、警局、估價廠 3 個單位拿文件 (2) 不知道文件順序與期限 (3) 進度不透明，等保險公司 3-7 週。本案提供「理賠案件建檔 + 文件檢核 + 進度追蹤 + 服務中心地圖」。

### 1.2 目標使用者
- **Primary — 出險保戶**：車禍 / 醫療 / 財損 緊急當下
- **Secondary — 保險業務**：協助客戶送件，效率工具

### 1.3 核心價值主張
> 一頁看完理賠案件：缺什麼文件 / 現在進度 / 哪裡最近 — 不用打電話催。

### 1.4 Non-Goals
- ❌ 真實保險公司 API 串接（無公開 API）
- ❌ 保險商品比較
- ❌ 保單管理

---

## §3 FR

- FR-001: 理賠案件建檔（事故類型 / 保單 / 損失）
- FR-002: 文件檢核清單（依案件類型自動生成）
- FR-003: 文件上傳 + 加密儲存
- FR-004: 進度看板（送出 → 審核 → 補件 → 結案）
- FR-005: 服務中心地圖（最近產險 / 醫院 / 警局）
- FR-006: 提醒（補件期限 / 開會時間）

## §4 NFR

- 文件加密 at-rest
- HIPAA-equivalent 等級
- 個資保留 7 年後自動銷毀

## §5 技術棧

- Vite + React 19 + TS strict
- Leaflet 地圖
- IndexedDB（離線可用）
- S3-compatible 儲存
